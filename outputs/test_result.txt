Context:
CREATE TABLE salesperson (salesperson_id INT, name TEXT, region TEXT); INSERT INTO salesperson (salesperson_id, name, region) VALUES (1, 'John Doe', 'North'), (2, 'Jane Smith', 'South'); CREATE TABLE timber_sales (sales_id INT, salesperson_id INT, volume REAL, sale_date DATE); INSERT INTO timber_sales (sales_id, salesperson_id, volume, sale_date) VALUES (1, 1, 120, '2021-01-01'), (2, 1, 150, '2021-02-01'), (3, 2, 180, '2021-01-01');

Question:
What is the total volume of timber sold by each salesperson, sorted by salesperson?

SQL:


SQL generado:
Here's the SQL translation:

```sql
SELECT s.name, SUM(t.volume) AS total_volume
FROM salesperson s
JOIN timber_sales t ON s.salesperson_id = t.salesperson_id
GROUP BY s.name
ORDER BY s.name;
```

Explanation:

1. We join the `salesperson` table with the `timber_sales` table on the `salesperson_id` column to link each sale to its corresponding salesperson.
2. We use the `SUM` aggregation function to calculate the total volume of timber sold by each salesperson.
3. We group the results by the `name` column in the `salesperson` table, so that we get the total volume for each salesperson.
4. Finally, we sort the results by the `name` column to show the total volume for each salesperson in alphabetical order.
